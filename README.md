# NexoBarrio

Frontend de Next.js, React y GSAP. Funciona sin backend. Los perfiles de demostración, publicaciones y actividad se guardan en el almacenamiento local de cada navegador y no se comparten entre dispositivos.

## Iniciar con npm

Necesitas Node.js 24 y npm. En PowerShell, desde esta carpeta:

```powershell
npm install
npm run dev
```

Abre http://localhost:3000. Si ya tenías el servidor abierto, detenlo con Ctrl+C y vuelve a ejecutar npm run dev.

Para compilar: npm run build.
