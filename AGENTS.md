# NexoBarrio — Instrucciones para Agentes

Este proyecto es una aplicación Web Next.js + React para el frontend y FastAPI + Supabase para el backend.
- **Frontend:** Next.js, React 19, Tailwind CSS y animaciones GSAP.
- **Backend:** Python 3.10+, FastAPI y Supabase ubicado en `backend/`.
- **Gestor de paquetes Node:** npm y `package-lock.json`.
- **Comprobación:** `npm run build` y `npm exec -- tsc --noEmit`.
